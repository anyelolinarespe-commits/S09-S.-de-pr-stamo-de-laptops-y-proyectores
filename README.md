# Caso Práctico: Sistema de Préstamo de Laptops y Proyectores

## Enunciado del Caso Práctico
> **"Caso práctico: Sistema de préstamo de laptops y proyectores"**  
> *La universidad cuenta con un módulo donde los estudiantes pueden solicitar temporalmente laptops, proyectores y otros equipos para exposiciones o trabajos académicos. Actualmente, el sistema solo registra el nombre del estudiante y el equipo solicitado.*

---

## Archivos del Proyecto
- **`index.html`**: Página web interactiva y responsiva con la interfaz del sistema.
- **`styles.css`**: Hoja de estilos moderna con diseño adaptable y profesional.
- **`app.js`**: Lógica de almacenamiento (`localStorage`), registro en tiempo real, búsqueda y control de estados (Prestado / Devuelto).
